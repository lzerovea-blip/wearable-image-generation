# 执行和产物规范

本文件定义实际生图、图生图、动图和视频任务的执行入口、输出目录、动画验收和失败处理。除非用户明确只要提示词，默认必须生成可检查的图片、动图或视频文件。

硬性要求：文生图、图生图、文生动图和图生动图中的图片生成、图片改写、首帧/过程帧/尾帧生成必须使用 `imagegen`。本地脚本只允许用于合成、校验、移动、整理或确定性过渡插帧，不允许替代 `imagegen` 生成新的页面内容。

默认动画交付：`imagegen` 生成真实 UI 内容关键帧，本地帧合成器 / motion assembler 负责确定性插帧、透明背景、尺寸校验和格式封装。用户说“动图”时默认输出 GIF；用户明确说“视频 / MP4 / video”时默认输出 MP4。`imagegen` 直接生成动图或视频不是默认交付方式；即使额外生成，也只能作为参考产物，不能替代 `frames/*.png`、最终动画文件和 `generation-report.md`。

例外：当输入是竖向 Swiper 导航点、小组件焦点移动等纯 UI 状态变化，并且目标是严格保持原图几何时，本地脚本可以复制原图或 `imagegen` 修正后的首帧，只在测量出的局部区域替换蓝色焦点状态。该路径不得新增页面内容，不得重绘组件规格，必须在报告中说明使用确定性后处理。

滑动过渡例外：当首页首帧和详情页尾帧已由 `imagegen` 生成或修正后，`scripts/render_vertical_transition_frames.py` 可以只做两页之间的垂直位移插帧。该脚本不得新增、删除或改写页面内容，只用于表达滑动过程。

圆形穿戴屏 UI 的最终 PNG 默认必须保留透明 alpha 通道：圆形屏幕内保留内容，圆形屏幕外的四角和外部区域 alpha=0。只有用户明确要求黑色背景、完整方形画布或设备展示图时，才保留圆外实底背景。

## 输出目录

每个任务创建一个独立目录：

```text
outputs/<YYYYMMDD-HHMMSS>-<ability>-<slug>/
├── final.png                  # 静态图任务
├── animation.gif              # 动图任务
├── animation.mp4              # 视频任务
├── frames/
│   ├── 001-first.png
│   ├── 002-middle.png
│   ├── 003-middle.png
│   └── ... / final frame
└── generation-report.md
```

`ability` 使用固定英文值：

- 文生图：`text-to-image`
- 图生图：`image-to-image`
- 文生动图：`text-to-animation`
- 图生动图：`image-to-animation`

`slug` 用 2-6 个英文小写词描述任务；不确定时使用 `health-ui`、`wearable-ui` 或 `animation`。

## 静态图执行入口

- 文生图：读取规范和功能原型后，调用内置 `imagegen` 生成 PNG，并把选定结果保存为 `final.png`。
- 图生图：先用 `view_image` 检查输入图可读性，再调用内置 `imagegen` 编辑、重绘或参考生成，并把选定结果保存为 `final.png`。
- 图生图组件裁片：默认最终 `final.png` 与参考图同像素尺寸；若生成结果尺寸不同，使用 `python3 scripts/normalize_to_reference.py --input <generated.png> --reference <reference.png> --out <final.png>` 归一到参考图尺寸。
- 圆形穿戴屏：`imagegen` 产物落盘后，运行 `python3 scripts/mask_round_screen_alpha.py --input <generated.png> --out <final.png> --mode inscribed-circle`；若还需要尺寸归一化，先归一化再做圆形 alpha 后处理。
- 圆形穿戴屏 PNG 必须是 RGBA 或等价带 alpha 通道的 PNG；四角 alpha 必须为 0。不得保存为 JPG，也不得交付圆外黑色实底的方形 PNG。
- `generation-report.md` 必须记录：能力、输入摘要、参考图路径、功能原型、设计规范、最终提示词、`imagegen` 调用方式、产物路径、检查结果。

如果 `imagegen` 不可用，只能输出提示词时，不要声称已生成图片；必须按“失败处理”记录降级。不得使用本地绘图、截图拼接、空白占位图或测试图片冒充 `imagegen` 产物。

## 动画和视频输出规范

默认动画链路先生成可检查帧序列，再按用户要求封装：

- 默认时长：4 秒；允许范围：3-5 秒。
- 默认帧数：至少 3 个关键状态，分别对应首帧、过程帧、尾帧；连续刷新、绘制或同步动效推荐 8-12 帧。
- 默认命名：`001-first.png`、中间帧按顺序命名为 `002-middle.png`、`003-middle.png` 等，最后一帧命名为 `final` 语义。
- 动图默认合成命令：`python3 scripts/assemble_animation.py --frames <frames_dir> --out <output.gif> --duration 4 --normalize-to first`
- 视频默认合成命令：`python3 scripts/assemble_video.py --frames <frames_dir> --out <output.mp4> --duration 4 --fps 12 --normalize-to first`
- 动图默认产物必须保留 `frames/` 下的关键帧 PNG 和 `animation.gif`。
- 视频默认产物必须保留 `frames/` 下的关键帧 PNG 和 `animation.mp4`；可附加 `animation.gif` 作为预览，但不能替代 MP4。
- 视频编码优先使用 PATH 中的 `ffmpeg`；如果没有，则使用 Python 包 `imageio-ffmpeg` 提供的 ffmpeg。若两者都不可用，输出失败报告，失败类型为“视频编码器不可用”，不得声称已生成 MP4。
- MP4 默认使用 H.264 / yuv420p，保证常见播放器可打开。MP4 不承诺 alpha 透明；圆表透明验收以 `frames/*.png` 四角 alpha=0 为准。
- 直接由 `imagegen` 输出的动图或视频文件不作为默认验收产物。

滑动/详情页过渡：

- 用户明确要求“下滑 / 滑动 / Swiper / 查看更多详情”时，默认先用 `imagegen` 生成首页首帧和详情页尾帧，再用 `python3 scripts/render_vertical_transition_frames.py --first <home.png> --final <detail.png> --out <frames_dir> --frame-count 9 --round-mask` 生成连续位移帧。
- 该脚本表达“首页内容整体向上移动，详情页从下方进入”的真实过渡；圆形穿戴屏使用 `--round-mask` 保持四角 alpha=0。
- 如果是带右侧 Swiper 导航点的页面，必须让首页和详情页的导航点焦点状态不同，并在中间帧体现焦点同步变化；优先给滑动脚本增加导航点覆盖层，例如 `--nav-centers "x,y;x,y;..." --nav-clear-box x,y,w,h --nav-active-from 0 --nav-active-to 2 --nav-switch-progress 0.5`，让过半帧切换或淡入详情页焦点，避免两页各带一组静态导航点。导航覆盖层必须保留原帧 alpha：清除框只作用于当前圆形内容的不透明区域，不能把透明过渡空档填成黑色竖条、矩形边缘或实底补丁。
- 不允许只生成首尾两张静态图、几张相似首页图，或只有局部卡片变化却没有进入详情页。

圆形详情页安全区：

- 圆表“查看更多详情页”尾帧包含睡眠摘要、运动摘要、情绪摘要时，优先使用三行紧凑列表布局；若使用卡片，最多三张紧凑列表卡片。
- 三个摘要项的总高度不得超过圆形屏可用安全区；第三项底部必须完整落在圆形底边 6vp 安全区以上，不能被圆弧截断或贴边。
- 详情尾帧通过 `imagegen` 生成后，先测量三张摘要项或三行列表的边界框，运行 `python3 scripts/verify_round_summary_layout.py --image <detail-final.png> --boxes "x,y,w,h;x,y,w,h;x,y,w,h"`。
- 若校验失败，必须自动重试尾帧，提示词改为“更紧凑三行列表、缩小卡片高度/字号/行距/图标、去掉装饰外发光”；仍失败时写失败报告，不进入 GIF/MP4 合成。
- 详情摘要背景使用低对比纯色列表行，只保留极弱分隔线；不使用外发光、霓虹边缘、厚重渐变、边线高光、高光玻璃质感。若轻微透明产生 AI 渐变或发光感，改用纯色行。

动画和视频验收：

- `animation.gif` 必须是多帧文件，不能用单张静态图冒充。
- 用户明确要求视频时，`animation.mp4` 必须存在、非空、可被 ffmpeg 或等价工具读出视频流，时长约 3-5 秒，帧数大于 1。
- GIF 和 MP4 都必须由可检查的 `frames/*.png` 合成；不得只提交 `imagegen` 直接生成动图或视频而缺失关键帧和报告。
- 所有关键帧必须同尺寸；合成前先校验尺寸，若 `imagegen` 输出轻微尺寸差异，统一归一化到首帧或目标尺寸并在报告中记录。
- 圆形穿戴屏动画的每个关键帧都必须在合成前运行圆形 alpha 后处理；`frames/` 中用于合成的 PNG 四角 alpha=0，圆外区域透明。
- `frames/` 中的首帧和尾帧必须来自 `imagegen` 生成或改写后的图片；滑动类中间帧可以由 `scripts/render_vertical_transition_frames.py` 基于首尾帧确定性插帧，其他过程帧必须来自 `imagegen` 或明确允许的确定性后处理。合成脚本只负责把这些帧封装成 GIF 或 MP4。
- 滑动类动画默认 8-12 帧；中间帧必须能看到连续位移、滚动或 Swiper 过渡，不能只有首尾静态帧或几张相似图。
- “查看更多详情页”尾帧必须进入详情页，并展示用户指定的详情模块；用户要求睡眠摘要、运动摘要、情绪摘要时，这三个模块标题和短摘要都必须可见。
- 圆表详情尾帧若包含三项摘要，必须通过 `scripts/verify_round_summary_layout.py` 的三项测量框检查；第三项底部不得超过圆形底边安全线。
- 右侧 Swiper 导航点必须与页面切换同步：点数与页面数量一致，焦点随首页到详情页变化；如果不是 Swiper，必须通过内容整体位移体现普通纵向滚动。
- 首帧、过程帧、尾帧必须能对应需求中的起始态、变化态和结果态。
- 所有帧必须保持同一页面类型或同一组件裁片类型；心率曲线任务必须保持同一心率趋势详情页，禁止新增健康总览卡片、步数/睡眠/血氧卡片或其他页面模块。
- 曲线刷新类动画必须覆盖关键进度点，例如 `00:00 / 04:00 / 08:00 / 12:00 / 16:00 / 20:00 / 24:00`。
- 三帧布局应稳定：设备形态、导航位置、主数据区域、字体和安全区不应漂移。
- 运动元素只服务加载、切换、反馈、数据变化、告警或完成状态。
- 每一帧都必须符合手机 App 或穿戴设备设计规范，并使用 HarmonyOS Sans / 鸿蒙字体。
- 圆形屏底部文字、底部控件和右侧导航点必须明显内收，不得贴近圆形弧边。
- 可见中文文案必须准确、短句、可读；报告中列出所有可见文案并检查错字、伪词和语义不通顺问题。
- 摘要模块图标必须采用扁平、简洁、小屏可读的官方截图/组件图标语言，不使用 3D、拟物、高光或复杂插画。
- 摘要模块容器必须避免外发光、厚重渐变、边线高光和玻璃高光；如果轻微透明仍导致 AI 光效，应改为低对比纯色列表项，并只保留极弱分隔线。

## 输入身份和参考图保真

- 图生图和图生动图默认锁定输入图画幅比例、裁片边界、组件形态、可见元素、点数、焦点尺寸和边缘关系。
- 图生动图输入首帧存在明显错字、伪文案或语义不通顺时，默认先用 `imagegen` 修正首帧文字并保持首页结构，再用修正后首页作为 `001-first.png`；若用户要求严格保留输入图或修正失败，在 `generation-report.md` 标记“输入缺陷未修正”，列出原始错误文案，并说明该缺陷只来自输入图。若用户要求最终 GIF/MP4 完全无错字，带错字输入帧不得进入合成。
- 不得默认把组件裁片扩展成完整页面；如用户要求或设计必须扩展，必须在 `generation-report.md` 写明允许扩展说明。
- 参考图只露出卡片上缘或局部内容时，输出必须保持同等裁片关系；不得补全被裁掉的卡片下半部，不得为了展示新内容改变裁片内的信息密度。
- 如果输出尺寸与参考图不同，必须保持同一画幅比例和裁片关系，并在 `generation-report.md` 记录尺寸变化；没有明确目标尺寸时，不应把小裁片放大成高信息密度的新区域。
- 参考图内容过弱时，在 `generation-report.md` 标记“参考图内容弱/需补原型假设”，并锁定仍可见的白底、分隔线、列表行高、状态区位置等元素。
- 竖向 Swiper 导航点必须保留点数、方向、主焦点尺寸和完整显示，并向屏内轻微内收。
- 小组件裁片执行图生动图时必须像素级几何锁定：保留点半径、点距、主焦点尺寸、弧边关系和组件尺度；只移动/替换蓝色焦点状态，不重新生成点半径、间距、弧线和裁片尺度。
- 竖向 Swiper 小组件动图优先走确定性后处理：以参考图或修正首帧为底图，使用 `scripts/render_swiper_focus_frames.py` 复制生成每帧，只替换蓝色焦点点位，再用 `scripts/verify_swiper_geometry.py` 校验参考尺寸和清除框外像素不变。不能测量点位、清除框或焦点尺寸时，必须报告失败；不要让 `imagegen` 重新生成大尺寸组件后继续合成。
- 如果任务没有用户输入的小组件裁片，但属于圆屏健康摘要、三叶草或右侧竖向 Swiper，可先读取 `运动健康素材/官方设计规范/功能截图/华为穿戴/健康摘要与三叶草/swiper` 作为测量参考；报告中注明这是“内置 Swiper 参考组”，不要把它当成用户输入图。
- 若仍使用 `imagegen` 结果作为中间帧，必须先裁切/缩放回参考图尺寸，再检查点数、点距、主焦点高度、弧边位置和裁片尺度；未通过检查时写失败报告，不进入 GIF 合成。

## 失败处理

失败时输出 `generation-report.md`，使用以下模板：

```markdown
# 生成失败报告

- 能力：[文生图 / 图生图 / 文生动图 / 图生动图]
- 输入：[用户需求或参考图路径]
- 失败类型：[素材缺失 / imagegen 不可用 / 参考图不可读 / 关键帧生成失败 / 详情页安全区检查失败 / 滑动过渡生成失败 / 圆形透明后处理失败 / 动画合成失败 / 视频编码器不可用 / 视频合成失败]
- 已尝试工具/路径：[imagegen、view_image、scripts/verify_round_summary_layout.py、scripts/render_vertical_transition_frames.py、scripts/mask_round_screen_alpha.py、scripts/assemble_animation.py、scripts/assemble_video.py、ffmpeg、imageio-ffmpeg、素材路径等]
- 是否降级为提示词：[是 / 否]
- 已产出内容：[提示词、关键帧、部分图片、无]
- 下一步需要：[用户补充参考图 / 提供素材路径 / 恢复生成工具 / 重新生成关键帧 / 检查脚本依赖]
```

失败类型处理：

- 素材缺失：继续使用 `references/` 内置规范；只有必须用截图、组件、字体或模板时才询问用户。
- imagegen 不可用：输出完整提示词和报告，明确“未生成图片产物”。
- 参考图不可读：说明不可读路径或格式，要求用户重新提供图片；不能凭空执行图生图或图生动图。
- 关键帧生成失败：保留已生成帧和提示词，说明缺少哪一帧。
- 详情页安全区检查失败：保留详情尾帧、测量框和脚本输出，记录第三项底部或摘要总高度失败原因；必须重试为更紧凑三行列表，不能把失败尾帧进入合成。
- 滑动过渡生成失败：保留首页帧和详情页帧，记录是否缺少连续位移、详情页尾帧、导航点同步或指定详情模块；不得把静态首页局部变化当作滑动动图交付。
- 圆形透明后处理失败：保留原始 PNG，记录脚本错误、输入尺寸、目标圆形边界和四角 alpha 检查结果；不得交付圆外黑底图作为最终圆形穿戴产物。
- 小组件几何检查失败：保留参考图和已生成帧，说明失败项，例如点数、点距、主焦点高度、弧边位置、裁片尺度或参考尺寸不一致；不得进入 GIF 合成。
- 动画合成失败：保留 `frames/`，记录脚本错误；不能把单帧 PNG 当作 GIF 动画交付。
- 视频编码器不可用：保留 `frames/` 和提示词，记录 PATH 中未找到 `ffmpeg` 或无法导入 `imageio-ffmpeg`；不得声称已生成 MP4。
- 视频合成失败：保留 `frames/`，记录 `scripts/assemble_video.py` 或 ffmpeg 错误；不能把 GIF 或单帧 PNG 当作视频交付。

## 报告检查项

完成时，`generation-report.md` 至少包含：

- 能力和目标载体。
- 输入需求和参考图路径。
- 使用的设计规范和功能原型。
- 最终提示词或每帧提示词。
- 产物路径：`final.png`、`animation.gif` 或 `animation.mp4`。
- 输出格式：PNG / GIF / MP4；视频任务记录 fps、时长、编码器来源和 MP4 可读性检查。
- 每帧来源：哪些帧由 `imagegen` 生成，哪些帧由本地脚本从已生成关键帧确定性插帧或后处理。
- 动画帧数选择理由。
- 输入图身份锁定项。
- 允许扩展说明。
- 参考图弱信息标记。
- 裁片边界、可见范围和信息密度检查。
- 圆形穿戴图透明背景检查：PNG 有 alpha 通道、圆外区域透明、四角 alpha=0；如用户要求保留黑色背景或完整方形画布，记录该例外。
- 视频透明说明：MP4 不承诺 alpha 透明；圆表透明验收记录 `frames/*.png` 四角 alpha=0，不能用 MP4 外底色代替 PNG 透明检查。
