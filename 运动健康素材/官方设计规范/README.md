# 华为开发者官方设计规范素材区

本目录用于保存和索引华为开发者设计站点的公开设计要求与设计资源，作为后续拆解华为运动健康 App、华为穿戴界面、控件、UX 和 icon 的官方基线。

## 来源入口

- 官方入口：https://developer.huawei.com/consumer/cn/design/devstart/
- 采集日期：2026-06-10
- 采集原则：只保存公开可访问资源，不绕过登录、权限或付费限制。

## 目录说明

- `设计要求/`：设计原则、布局、视觉、交互、组件、动效、多设备适配等学习笔记。
- `组件资源/`：官方组件库、组件模板、设计套件等资源。
- `Icon资源/`：官方图标、符号、图标规范相关资源。
- `模板资源/`：官方设计模板、界面模板、可复用设计文件。
- `视觉资源/`：色彩、字体、插画、品牌视觉或其他视觉系统资源。
- `示例截图/`：官方页面示例、组件示例、设备示例截图。
- `下载记录/`：资源下载记录、失败记录、待人工下载清单。


## 统一口径

涉及 App 或穿戴设备界面生成、拆解和后续图生图提示词时，字体统一使用鸿蒙字体。
