# 血糖研究结果来源说明设计

## 目标

在现有“血糖健康研究”结果页中明确说明当前主结果来源于手表，同时保留未来支持戒指和多设备融合的文案扩展能力。

## 页面修改

- 保持参考图的画幅、页面结构、卡片形态、色彩、字号层级和现有文案不变。
- 在主结果卡片内、日期 `2026/6/2 - 2026/6/6` 下方新增一行轻量来源说明。
- 新增文案为 `结果来源：手表`，左侧使用扁平、简洁的手表线性图标。
- 来源行使用次级灰色文字，不与橙色风险等级争夺视觉焦点。
- 通过适度增加卡片内容区纵向空间保持原有呼吸感，禁止遮挡或压缩正文。

## 扩展规则

同一组件未来可将值替换为 `戒指` 或 `手表、戒指`，标签名始终保持 `结果来源`。下方历史记录中的 `手表筛查`、`戒指筛查` 继续表示单次筛查设备，不承担整份合并结果的来源说明。

## 生成与验收

- 任务类型：图生图；目标载体：手机 App 完整页面。
- 使用 HarmonyOS Sans / 鸿蒙字体，禁止生成 iOS 状态栏或 Home Indicator。
- 输出尺寸归一到参考图尺寸。
- 逐项检查新增中文文案、图标可读性、卡片对齐、内容遮挡和页面风格一致性。
- 最终输出 `final.png` 和 `generation-report.md`。
